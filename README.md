# JAC Motors Tajikistan

Сайт официального дистрибьютора JAC в Таджикистане (Koinot Auto).

- **Стек:** Laravel 13, MySQL 8, Filament 5 (админка), Tailwind CSS 4, Alpine.js, Swiper, Vite.
- **Языки:** русский (основной), таджикский, английский — `/ru/...`, `/tg/...`, `/en/...`.

## Установка

```bash
composer install
cp .env.example .env
php artisan key:generate
# создайте базу jacmotors (utf8mb4) и укажите доступы в .env
php artisan migrate --seed
php artisan storage:link
npm install && npm run build
php artisan make:filament-user          # администратор
```

Для разработки: `composer run dev` (сервер, очередь и Vite одновременно).

### Перенос контента со старого сайта

```bash
php artisan jac:import-legacy /path/to/old/jacmotors.tj
```

Команда разбирает старые Blade-страницы и заполняет модели (баннеры, цвета, описания, блоки «Экстерьер / Интерьер…», PDF с комплектациями, 3D-туры), слайдер главной, руководства и регламенты ТО. Файлы копируются из старого `public/storage`, а недостающие скачиваются с jac-motors.kz. Если в PHP нет корректного набора корневых сертификатов, укажите его явно: `--ca="C:/Program Files/Git/mingw64/etc/ssl/certs/ca-bundle.crt"`. Команду можно запускать повторно.

## Админка — `/admin`

| Раздел | Что там |
|---|---|
| Заявки | Все заявки с сайта (обратный звонок, тест-драйв, покупка, сервис, поддержка) со статусами и комментариями менеджера. Счётчик новых — в меню |
| Модели | Карточка, баннеры, цвета, блоки страницы, характеристики, галерея, PDF, 3D-тур, SEO. Порядок меняется перетаскиванием |
| Категории | Пикапы, кроссоверы, легковые, коммерческие |
| Слайдер на главной | Баннеры с привязкой к модели или ссылкой |
| Дилеры и сервис | Адреса, телефоны, режим работы, карта |
| Акции и новости | Публикации с датой и сроком действия акции |
| Руководства и регламенты | PDF-файлы для владельцев |
| Страницы | «О компании», «Гарантия», «Политика конфиденциальности» |
| Настройки сайта | Телефон, e-mail, адрес, соцсети, **адреса для уведомлений о заявках**, ID Google Analytics и Яндекс.Метрики |

Тексты вводятся на трёх языках (вкладки RU / TJ / EN). Если перевода нет, показывается русский текст.

## Устройство

- `app/Models` — модели; переводимые поля хранятся в JSON (`{"ru": "...", "tg": "...", "en": "..."}`) и читаются через `$model->tr('field')` или хелпер `tr()`.
- `app/Http/Middleware/SetLocale.php` — язык из префикса URL; `route()` подставляет текущий язык автоматически.
- `app/Http/Controllers/LeadController.php` — приём заявок: валидация (`StoreLeadRequest`), защита от спама (honeypot и лимит 3 заявки в минуту с IP), сохранение в БД, письмо на адреса из настроек.
- `lang/{ru,tg,en}` — тексты интерфейса.
- `resources/views` — Blade-шаблоны; формы заявок — компонент `x-lead-form`, модальные окна — `partials/modals`.
- Старые адреса (`/jac-t6`, `/models`, `/feedback`…) отдают 301-редирект на новые.
- `/sitemap.xml` строится автоматически с учётом всех языков (hreflang).

## Деплой (cPanel)

1. Корень домена должен указывать на папку `public`. Если это невозможно, используйте `.htaccess` в корне с перенаправлением в `public/`, как на старом сайте.
2. В `.env`: `APP_ENV=production`, `APP_DEBUG=false`, `APP_URL=https://jacmotors.tj`, доступы к БД и SMTP (`MAIL_MAILER=smtp` …).
3. `composer install --no-dev -o`, `php artisan migrate --force`, `php artisan storage:link`, `npm run build` (или загрузите готовую `public/build`), `php artisan optimize`.
